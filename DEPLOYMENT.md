# Website deployment

AdenTech's public website is hosted using GitHub Pages from this repository.

## Website file

- `index.html` — the public website.

## Publishing changes

1. Review changes to `index.html` before committing.
2. Commit and push approved website changes to the configured GitHub Pages branch.
3. Check the published website and contact form after deployment.

Do not put credentials, customer information, private automation code, or internal operating procedures in this public repository.
